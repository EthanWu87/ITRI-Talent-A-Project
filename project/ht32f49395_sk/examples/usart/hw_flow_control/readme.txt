  this demo is based on the ht32f49395_sk board, in this demo, provides a description
  of how to use the usart hardware flow control function, the demo communicate with
  the hyperterminal.

  set-up
  - connect usart2 tx pin(pd5)/rx pin(pd6)/cts pin(pd3)/rts pin(pd4)
