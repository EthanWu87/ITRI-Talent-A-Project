  this demo is based on the ht32f49395_sk board, in this demo, pa8 output 47 khz
  waveforms, pa8 toggled each pa3, pa6, pa7 edge.
  pin connection:
  - pa0    <--->    pa3
  - pa1    <--->    pa6
  - pa2    <--->    pa7
