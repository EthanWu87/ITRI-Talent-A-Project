  this demo is based on the ht32f49395_sk board, in this demo, shows how to use
  the adc repeat mode conversion and use dma loop mode transfer conversion data.
  the convert data as follow:
  - adc1_ordinary_valuetab[0] ---> adc1_channel_4
  - adc1_ordinary_valuetab[1] ---> adc1_channel_5
  - adc1_ordinary_valuetab[2] ---> adc1_channel_6
